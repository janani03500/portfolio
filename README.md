# Janani M | Portfolio Website

My personal portfolio, showing my work as a full-stack developer and as an ML / data analyst.

**Live site:** https://janani03500.github.io/portfolio

## Sections
- **Home:** short introduction
- **About me:** education, location, languages and what I'm looking for
- **Projects:** NutriVision AI, Customer Delinquency Prediction, Air Quality Prediction, Movie Recommendation System and more, with filters for web, mobile, machine learning and data analysis
- **Experience:** internships, training and education
- **Skills:** web development, machine learning, data analysis and tools
- **Certifications, talks and activities**
- **Contact:** email, GitHub and LinkedIn

## Features
- Two colour themes, Ocean (light blue) and Navy (dark blue), with a switch in the menu. The choice is remembered.
- Scroll animations, a scroll progress bar and a menu that highlights the current section
- Project filters
- Responsive layout for phones, tablets and computers
- Respects the "reduce motion" setting on visitors' devices

## Built with
HTML, CSS and JavaScript in a single `index.html` file, with Google Fonts (Bricolage Grotesque and Public Sans). No frameworks or build steps.

## Run it locally
```bash
git clone https://github.com/janani03500/portfolio.git
cd portfolio
```
Open `index.html` in your browser.

## Deploy with GitHub Pages
1. Go to **Settings → Pages** in this repository.
2. Under "Build and deployment", choose **Deploy from a branch**.
3. Select the `main` branch and the `/ (root)` folder, then click **Save**.
4. After a minute or two, the site is live at the link above.
